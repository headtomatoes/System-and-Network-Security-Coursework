# Context

Glossary of the domain language for this module: System & Network Security.

**Scope rule.** This file holds *security* terminology only — the vocabulary the module
itself uses. It is a glossary and nothing else: no implementation details, no plan, no
study notes. The prep-plan's own vocabulary (Prereq Gap, Diagnostic, Deep Block, Lab,
Glossary) deliberately lives in [ROADMAP.md](ROADMAP.md) instead, because mixing two
unrelated domains in one glossary makes it useless as either.

Each entry is one tight paragraph, targeting *recognition* — enough that the term never
stops you mid-slide. Depth belongs in `docs/homework/`, not here.

## Terms

*Empty by design.* This file is filled during Block 3 of the roadmap, which is blocked
on the syllabus arriving — the terms worth writing are the ones this module actually
uses, and guessing them would spend a quarter of the total budget on vocabulary that
may not appear. Terms also get added opportunistically whenever one is resolved during
a session.
